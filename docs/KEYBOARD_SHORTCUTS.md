# Keyboard Shortcuts

Kanyx supports the following keyboard shortcuts in the main window. These are available in the Windows and Linux desktop versions.

| Shortcut | Action |
| --- | --- |
| `Ctrl + N` | Create a new column on the current board. |
| `Ctrl + Shift + N` | Create a new board. |
| `Ctrl + F` or `Ctrl + L` | Focus the search field to search tasks, descriptions, and tags. |
| `Esc` | Clear the search text and reset the priority filter to **All**. |
| `Ctrl + 1` | Switch to the first board in the board selector. |
| `Ctrl + 2` | Switch to the second board, if available. |
| `Ctrl + 3` | Switch to the third board, if available. |
| `Ctrl + Z` | Undo the last supported action. |
| `Ctrl + Shift + Z` or `Ctrl + Y` | Redo the last undone supported action. |

## Notes

- Shortcuts are intended for the **main Kanyx window**. When a dialog is open or you are editing text, key combinations may behave differently.
- **Undo/redo** applies to selected board and task operations; not every action can be undone.
- `Ctrl + 1`, `Ctrl + 2`, and `Ctrl + 3` refer to the **order shown in the board selector**, not board names.

For bugs or shortcut suggestions, [open a GitHub Issue](https://github.com/zehnzwanzig/kanyx/issues/new/choose).
